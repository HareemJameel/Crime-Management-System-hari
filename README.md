# Crime Record Management System

## Java Project

A simple **Crime Record Management System** developed in Java to manage and organize criminal records, crime information, suspects, witnesses, investigators, police stations, and court cases.

### Project Overview

The Crime Record Management System is designed to make it easier to store, manage, and retrieve information related to criminal records.

The system helps organize different types of crime-related information and keeps records structured so that they can be easily maintained and accessed.

## Main Features

* Manage criminal person information
* Store and manage crime records
* Manage crime categories
* Maintain crime reports
* Manage police station information
* Store investigator details
* Manage suspects
* Manage witnesses and evidence
* Maintain court case information
* Test and run the system using the main driver class

## Project Structure

The project is organized into different Java classes, with each class responsible for a specific part of the system.

### Main Classes

1. **CriminalPerson** – Stores information about criminal persons.
2. **PoliceStations** – Manages police station information.
3. **CrimeRecord** – Handles criminal record information.
4. **CrimeCategories** – Contains different categories of crimes.
5. **CrimeReports** – Manages crime report information.
6. **Investigator** – Stores investigator details.
7. **WitnessesEvidence** – Manages witnesses and evidence related to cases.
8. **Suspects** – Handles information about suspects.
9. **CourtCase** – Manages court case information.
10. **TestDriver** – Main class used to run and test the project.

## Technologies Used

* **Java**
* **Object-Oriented Programming (OOP)**
* Java Classes and Objects
* Collections / Data Structures (where applicable)

## Purpose of the Project

The main purpose of this project is to demonstrate how Java and Object-Oriented Programming concepts can be used to develop a basic crime record management system.

It provides practice in designing multiple classes that work together to represent a real-world management system.

## How to Run

1. Clone the repository.
2. Open the project in **Visual Studio Code** or any Java-supported IDE.
3. Make sure Java/JDK is installed.
4. Open the `src` folder.
5. Run the **TestDriver.java** file to start the project.
